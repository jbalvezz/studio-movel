Política de Privacidade — Studio Móvel

Última atualização: 25 de novembro de 2026

O Studio Móvel é um aplicativo Android de uso pessoal, feito para que o próprio dono gerencie seus canais do YouTube e seus e-mails do Gmail.

Quais dados o app acessa

  • YouTube (permissão youtube.force-ssl): dados do canal, lista de vídeos, visibilidade, estatísticas e comentários, para exibir e permitir que o próprio dono edite seus vídeos e responda comentários.
  • Gmail (permissão gmail.modify): mensagens das contas conectadas, para exibir, responder e organizar e-mails.

Como os dados são usados e guardados

  • Os dados são lidos diretamente das APIs do Google e exibidos apenas no aparelho do usuário.
  • Não existe servidor do Studio Móvel: nenhum dado é enviado, vendido ou compartilhado com terceiros.
  • O app guarda no aparelho apenas o e-mail de cada conta conectada e o nome/foto do canal. Senhas nunca passam pelo app; o login é feito pelo próprio Google.
  • As permissões podem ser retiradas a qualquer momento em myaccount.google.com/permissions. Desinstalar o app apaga os dados guardados no aparelho.

Uso Limitado

O uso e a transferência, para qualquer outro app, de informações recebidas das APIs do Google seguirão a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
